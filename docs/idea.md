Spatial, temporal record and utilities for worldbuilding.
Main features:
- Spherical LOD world map, possible to add heightmap/textures (layered)
- Links to Media pages
- Timeline view (borders, cities, roads, travel records)
- Views should be layered

From continents to singular houses, this tool would allow for worldbuilding in a real, consistent manner.
Python script used to generate sectors manually (for Gaea refinement) already exists in python script (.ignored/python_script).
