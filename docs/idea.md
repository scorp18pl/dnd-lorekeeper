# Lorekeeper

Native desktop worldbuilding tool for spatially and temporally consistent fictional worlds — from solar systems down to individual buildings.

## Features

- **Globe** — 3D orbiting globe with overlays (no heightmap)
- **Overlays** — pin external maps (Gaea, Inkarnate, hand-drawn) to the globe by position and extent
- **Entities** — place POIs (cities, and so on) on the globe; SDF labels; lore `.md` links per entity
- **Timeline** — custom calendar; scrubber drives entity visibility, ownership history, and travel position
- **Roads & distance** — road and naval graph; Dijkstra distance tool with great-circle fallback
- **Party travel** — waypoint records interpolated on the scrubber; road-snapped; fading trail
- **Obsidian Integration** — The app should integrate with obsidian.md (used for content pages). Opening content pages for pois in obsidian editor if active should be allowed trough in-app actions. Also obsidian pages linked to pois should allow for the app to show the poi location.
